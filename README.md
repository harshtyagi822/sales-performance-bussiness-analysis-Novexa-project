# Sales Performance & Business Analysis – Novexa Project

## 📊 Project Overview

This project analyzes Superstore sales data to identify sales performance, profitability, customer trends, product performance, and regional business insights.

The analysis includes data cleaning, exploratory data analysis, KPI calculation, and business-focused visualizations to support data-driven decision-making.

## 🎯 Objectives

- Analyze overall sales and profit performance
- Identify profitable and loss-making products
- Analyze sales by category and sub-category
- Evaluate regional and customer-segment performance
- Understand the impact of discounts on profitability
- Identify important business trends and insights

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git & GitHub

## 🔍 Key Analysis Areas

### Sales Performance
- Total Sales
- Monthly and yearly sales trends
- Category and sub-category performance

### Profitability Analysis
- Total Profit
- Profit Margin
- Loss-making products
- Discount vs. Profit analysis

### Business Analysis
- Regional performance
- Customer segment analysis
- Top-performing products
- Products contributing to losses
